This page now reads a single Excel file — JTKiaz-Content-Workbook.xlsx — with one tab per sheet (Books, Chapters, Poems, Quotes, Music, Blog, Promo Popups). If you don't have Node.js installed, or running node build-data.js in a terminal isn't working for you, this page does the exact same job entirely in your browser.
